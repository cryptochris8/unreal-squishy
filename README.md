# Squishy Smash: The Lost Sparkle (Unreal Engine 5.8 + MCP)

A wholesome, no-combat cozy collector/explorer built in **Unreal Engine 5.8** for **Steam (PC)** — a fresh Unreal rebuild of the proven Roblox game *Squishy Smash*. You wander a storybook world and **squish sleepy plush "squishy friends"** to fill their Joy, popping them into sparkles and **Sparkle Coins**, then **discover and collect** them into a Squishy Book. *The Lost Sparkle* is **Book #2** of the real storybook: the world's Sparkle splits into three shards across three lands — reuniting them is the quest.

> Despite the name **"Smash," there is no fighting.** This is a kid-friendly, storybook-safe game. See `CLAUDE.md` §5.
